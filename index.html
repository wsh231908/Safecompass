自定义数据集格式

JSON 支持数组或包含 `cases` 数组的对象；CSV 第一行必须是字段名。每条用例至少需要一个文本字段： `prompt`、`goal`、`request`、`question`、`instruction`、`text` 或 `content`。

可选字段包括 `id`、`category`、`attack_type`、`behavior`、`behavior_type`。手动添加只需要输入测试 prompt，后台会自动补齐 `id`、`goal`、`source`、`category`、`behavior_type` 等评测字段。

自定义数据集评测固定使用 JailbreakBench Llama judge：先调用被测模型生成回复，再调用本地 Llama `meta-llama/Llama-3-70b-chat-hf` 对“原始请求 + 模型回复”判定 `safe` 或 `unsafe`，不使用简单模式匹配。
