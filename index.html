自定义数据集格式

JSON 支持数组或包含 `cases` 数组的对象；CSV 第一行必须是字段名。上传后会统一规范成 `safecompass.case.v1`。每条用例至少需要一个文本字段： `prompt`、`goal`、`request`、`question`、`instruction`、`text` 或 `content`。

标准字段包括 `id`、`source`、`dataset`、`subset`、`prompt`、`goal`、`category`、`behavior`、 `behavior_type`、`attack_type`、`target`、`metadata`。手动添加只需要输入测试 prompt，后台会自动补齐。

自定义数据集评测会先调用被测模型生成回复，再调用单 Judge 或多 Judge majority vote 对“原始请求 + 模型回复” 判定 `safe` 或 `unsafe`，并保留每个 Judge 的原始输出。

    "behavior_type": "custom",
    "metadata": {}
  }
